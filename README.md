# Kirby Access

A screen reader and audio mod for Kirby's Return to Dream Land on PC, using the
[Kirby Wii Recomp](https://github.com/ExpansionPak/ModernGekko/releases) port.
Menus, text and story are spoken through your screen reader, and gameplay is
told with positional sounds, so blind players can play the game from start to finish.

Download the zip from [Releases](../../releases). Everything about installing and
playing is in [README.txt](README.txt). [Kirby Stage Guide.txt](Kirby%20Stage%20Guide.txt)
is an optional, spoiler-filled guide for when you get stuck.

You need your own copy of the game (USA, SUKE01) as a .wbfs or .iso.
